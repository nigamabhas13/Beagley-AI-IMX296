# Licensing

This repository contains both project-specific work and material derived from the Texas Instruments Imaging software distribution.

## Project-specific work

The IMX296 Linux driver changes, BeagleY-AI device-tree overlays, scripts, and documentation in this repository are project-specific work. The applicable license for each source file is indicated by its file header where present.

## Texas Instruments material

The contents under `dcc/linear/` include DCC configuration source derived from the Texas Instruments Imaging software distribution. That material is provided under the Texas Instruments Text File License reproduced in `licenses/TI-TEXT-FILE-LICENSE.txt`.

The TI license permits source redistribution and modification subject to its terms, including the restriction that redistribution and use are licensed only for TI Devices.

Generated DCC binaries are intentionally not committed to this repository. They can be regenerated from the DCC source using `scripts/generate_dcc.sh` and the TI DCC generation tools.
